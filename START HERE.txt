LOCAL AGENT
Your own local desktop assistant for files, coding, and terminal commands.

OPEN IT

1. Extract the ENTIRE ZIP into a folder you can write to.
   Do not run the app from inside the ZIP preview.
2. Double-click "Start Local Agent.cmd".
3. If "Download model (3.3 GB)" appears, click it once and wait for the
   download to finish. Packages that already include the model skip this step.
4. Wait for "Local engine ready", then choose a working folder.
5. Type a task and click Send, or press Enter.

Python and Ollama are included. You do not need to install them separately,
create an account, or provide an API key. Codex is not required. Once the
model is downloaded, it runs on your computer and local chat works offline.
Commands you approve can still use the internet, for example to install
packages for a project.

TRY THESE TASKS

- "Look through this folder and explain the project."
- "Create a Python temperature converter and test it."
- "Find the cause of this error and fix the code."

CHAT CONTROLS

- Enter sends a message. Shift+Enter adds a new line. Ctrl+Enter also sends.
- You can send another message while the agent works. It is marked queued
  and is read before the agent's next step. It does not interrupt a response
  already being generated.
- Questions appear inside the chat. Pick an option and click Send answer,
  or type your own answer in the message box. Skip pauses for your next message.
- Reason more gives a supported model extra time to think about a task.
  It is disabled when the selected model does not support thinking.
- Elapsed shows time spent on the current task, including waits for you.
  Last generation tokens/s uses the model's reported generation speed;
  it appears after a response has finished.
- The agent can show a short plan and update its steps as it works.

FILES AND IMAGES IN CHAT

- Use Attach files beside the message box, or Ctrl+V to paste a screenshot
  or files copied in Explorer. Plain text paste works too. Right-click the
  message box or conversation for copy/paste options.
- Pending attachments appear above the message box and can be removed.
  Send an attachment alone or with instructions, including while work runs.
- Text/code, CSV, JSON, Markdown, DOCX text, and PNG/JPEG/GIF/BMP images
  are supported. Each file must be 25 MB or smaller. Up to eight attachments
  fit in a message, with four images at 16K context or one at 8K context.
- Images need a vision-capable model, such as the default Qwen3.5 model.
  A text-only coding model cannot see screenshots. Images are resized for
  inference, and GIF files use a single frame.
- Large text is excerpted initially; the agent can read more precise sections.
  DOCX images/layout and PDF files are not read. Export text or use screenshots
  for these cases. Image generation is not included.
- Attachments are copied into the local data folder and remain with saved chats.
  They are never included in automatic GitHub source uploads or app updates.

MODELS AND PERFORMANCE

Open Models & performance at the top of the chat to change these settings.

- Auto adjusts GPU use to the detected hardware and available video memory.
  You can also choose RTX 5060 desktop, RTX 4070 laptop, RTX 5080 desktop,
  or CPU. The profile is saved and applies when you start your next task.
  The panel shows detected hardware and available VRAM. Profiles do not
  guarantee a particular speed; the tokens/s counter always uses real results.
- To add an Ollama model, enter its model name and click Download. Model
  downloads need internet access and enough storage for the selected model.
- To import your own local weights, enter a new model name, choose a .gguf
  file, then click Import. Choosing a file alone does not import it.
- After downloading or importing, the model is selected in the sidebar.
  You can switch back to another installed model there.
- Presets offer the fast Qwen3.5 4B model and larger Qwen3.5 9B model.
  The 9B download is about 6.6 GB and may run more slowly on an 8 GB GPU.
  Selecting a preset only fills the model name; Download starts the transfer.

Agent work needs a model with tool calling and at least 8,192 context tokens.
The app uses up to 16,384 context tokens when the model supports them.
Models explicitly lacking these capabilities cannot start an agent task.
If capability information is missing, the app labels support as unknown;
an imported model is not guaranteed to work with file and command tools.
Model and performance controls are unavailable while a task or model transfer
is running. Selecting a profile or opening the panel never downloads a model.

WHEN IT WORKS ON FILES

The agent's file tools stay inside the folder you select. Before running
a terminal command, it shows the exact command in a chat card with Allow
once and Reject buttons. The visible "Always allow commands in this chat"
checkbox beside the message box lets commands run without repeated prompts.
It also approves a command currently waiting for you. The checkbox resets
when you start a new chat or reopen a saved chat.
Commands run with your Windows account and can access other folders.

Click Stop to cancel the current task and discard follow-ups still queued.
Stop does not undo changes already made. File-tool overwrites keep copies
in .localagent-backups inside the project. Changes made by terminal commands
do not automatically get backups.

The agent checks existing files before editing and can replace an exact,
unique block rather than rewriting a whole file. Stale reads and ambiguous
matches are rejected with a request to inspect the current file. Coding
instructions emphasize checking results before claiming that a fix works.

The app saves your last chat automatically. New chat archives the previous
conversation; use Saved chats to reopen it. A small local model may need
clear, specific tasks and corrections. Review changes before relying on them.

WORKING MEMORY

The model has a finite working memory. When a conversation or task gets
large, the agent summarizes older steps automatically so it can continue.
"Working memory summarized" tells you when this has happened. Your full
chat remains saved. The working summary keeps recent instructions and
useful facts, but cannot retain every detail. The agent can look back at
earlier messages when needed; you can also remind it of a critical detail.

Long tasks can continue past the initial 24-step checkpoint automatically.
Repeated actions that make no progress cause a pause. The agent also pauses
after 120 model steps or about an hour, at a safe step boundary. Your chat
stays saved; send "Continue" when you want it to keep working.

UPDATE THE APP

Click Update when no task is running. The updater can check the configured
GitHub release channel or install an update ZIP you received. Review the
version, then install it. The app restarts after a successful update.
App updates preserve your local models, chats, settings, and project files.
Checking online or downloading an update needs an internet connection;
ordinary local chat does not.

COMPUTER REQUIREMENTS

- 64-bit Windows 10 (22H2) or Windows 11.
- 16 GB RAM is suggested; more memory helps with larger projects.
- Enough free storage for the whole extracted package and your work.
- An NVIDIA GPU is optional. Speed depends on the computer and other apps.

If the normal launcher has GPU problems, close Local Agent and open
"Start Local Agent (CPU).cmd". CPU mode uses system memory and is slower.
Close games or other heavy apps if responses are slow or memory is low.
The first reply may take longer while the model loads.

The included Python can run Python programs. Other project tools, such as
Node.js, Git, Java, compilers, and package dependencies, are not included.
They need to be installed separately if your task requires them.

KEEPING OR SHARING YOUR COPY

Keep all files and folders together. You can move the whole extracted folder
after closing the app and stopping its local engine. Do not share only the
launcher: it needs the runtime and model files beside it.

Use the original distribution ZIP when sharing with someone else. After you
use the app, data contains your chats and settings, logs may contain task
details, and workspace may contain your files. These are personal. Make a
separate clean copy without your data, logs, or workspace contents before
resharing a used installation. Keep the included licenses and notices.

TROUBLESHOOTING

- Missing files: extract the entire ZIP again.
- Engine offline: use Refresh connection; check logs/ollama.log if needed.
- Startup error: check logs/desktop.log.
- If a project needs a missing tool, install that tool and reopen Local Agent.

This is a local assistant, not a guarantee that every task will succeed.
You control which project it works on and which terminal commands run.
